# Implementation Docs

This folder contains implementation-planning material for the capstone handover period.

Structure:

* `planning/`
  delivery planning, milestones, integration contract, team allocation, handover plan, and risk tracking
* `prs/`
  authoritative PR specifications organized by workspace hierarchy

Interpretation:

* use `planning/` to understand sequencing, contracts, scope, and owner expectations
* use `prs/` to define the minimum complete PR slices students should submit
