# Design Docs

This folder contains active design documentation for the platform.

Suggested reading order:

* `product/`
  product semantics, workspace hierarchy, workflow posture, and operating-model framing
* `system/`
  architecture and repo-level design decisions
* `backend/`
  API and backend ownership maps
* `database/`
  data model, schema, and persistence strategy
* `processes/`
  workflow maps and UX/process walkthroughs by scope
* `ds/`
  DS-facing dataset, runnable-task, and evaluation constraints
* `archived/`
  historical or superseded diagrams kept for reference
