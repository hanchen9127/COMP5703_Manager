# Terminology

This folder defines stable platform terms that should not drift across governance, design, implementation, or UI docs.

Current terms include:

* `governance-model.md`
* `project-lifecycle.md`
* `task-lifecycle.md`
* `queue.md`
* `task-schema-and-policy.md`

Use these files when a term risks becoming overloaded or when a workflow concept needs one canonical meaning across teams.
